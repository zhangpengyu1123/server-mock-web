# V6 · MOCK 实验台（MOCK LAB · Aurora Glass）

> **我心目中的 mock 工作台**：把平台当成一条**信号链**来做——对端网元 → 接入层 → 能力矩阵 → 响应引擎 → 审计带。
> 每来一次请求，就有一颗**会发光的信号珠**从链首走到它该停的节点；需要人放行的请求会**停在闸门前排队**。
> 底部是一条**可回放的时间带**：拖动播放头 = 回到那一刻，审计列表与监视器一起倒退。
> 视觉上走**柔美通透**的路线：极光在玻璃台面下缓慢流动，一切容器都是半透明的、会呼吸的。

## 一、设计语言：AURORA GLASS

前五版分别在「运维 HUD / 瑞士编辑 / PRTS 维基 / 莱茵档案 / 音乐台」上做文章，这一版**不再借用任何既有体系**，
用我自己的一套语言：**极光 + 玻璃 + 柔和几何**。

| 维度 | 选择 |
| --- | --- |
| 底色 | 浅雾 `#f4f2fa`，上面浮四团极光：薰衣草 `#c3b1ff`、蜜桃粉 `#ffc4d8`、薄荷 `#a8ecdd`、天空 `#b8d7ff`（`blur(60px)`，46–62s 缓慢漂移） |
| 容器 | 一切皆玻璃：`rgba(255,255,255,.62)` + `backdrop-filter: blur(22px) saturate(1.5)` + 1px 亮边 + 三层柔和投影（`0 14px 34px rgba(88,74,140,.12)`） |
| 主色 | 极光渐变 `linear-gradient(115deg,#9a7bff,#ff9ec9,#ffc6a8)`——只用在**主行动 / 选中 / 信号珠 / 播放头** |
| 语义色 | 成功薄荷 `#2fbe9b`、等待蜜桃 `#ff9a5c`、异常珊瑚 `#ff6f8b`；数字与标签用柔和紫灰 |
| 文字 | `#2b2544`（柔和的深紫灰，不用纯黑）/ 次要 `#7c7595` / 极淡 `#a49dbd` |
| 形状 | 卡片 18px、胶囊 999px、输入 14px；圆角与柔和投影是「柔美」的主要来源 |
| 排字 | 中文系统黑体；数字与英文标签等宽；标题用渐变文字（`background-clip: text`）；层级靠字重与字距，不靠颜色对比 |
| 双主题 | **晨雾**（浅）/ **夜航**（深：`#100e20` + 更亮的极光 + 玻璃 `.07`），只换 token，620ms 连续过渡，存 `localStorage['v6-theme']` |

**动效只走技能预设**（`ui-ux-pro-max` → 已落成 `_shared/button-fx.js` 与 `_shared/motion.js`）：

| 技能条目 | 本版落点 |
| --- | --- |
| Hover · Subtle（`y:-1`、150ms、位移 <2px） | `data-fx="subtle"`：抽屉、卡片行、细工具按钮 |
| Hover · Standard（`y:-4`、`scale:1.02`、阴影抬升、250ms） | `data-fx="standard"` 与 `.bar`（登记端点 / 创建账号 / 执行校验…） |
| Hover · Complex 磁吸（`elastic.out`、钳制 ×0.3、**一屏 ≤1–2 个**） | `.mx-magnetic` / `data-fx="magnetic"`：一次屏只给一个焦点 |
| 按下立即反馈（`active:scale-95`）+ 抬起弹簧归位 | `MP.btn` 全局委托：`scale(.97)` + 涟漪 + 合成音 |
| 异步 >300ms 必须 loading（最短 300ms、`aria-busy`） | 本版 **12 处** `MP.btn.loading()`：签发证书、触发接口、参数校验、推进任务、软件包校验、虚层校验… |
| Loading / Skeleton：渐变扫光 1.2–1.6s，且**内容挂载后必须 kill** | `MP.micro.latticeLoader` 只在校验进行中存在，完成后由重画替换掉（不留孤儿循环） |
| 缓动纪律：退出比进入快、只用 transform/opacity | 面板入场 360ms → 退出 200ms；信号珠、极光、播放头全部只动 `transform / opacity` |
| `prefers-reduced-motion` | CSS 全量 `.01ms` + `MP.motion.reduced`：信号珠直接跳过、极光停漂 |

额外的**语义化动效**（不是装饰，都在表达状态）：
**信号珠沿链流动 = 一次请求的旅程**；**珠子停在闸门前 = 等待人工**；**播放头位置 = 当前时间**；
**极光漂移 = 背景生命感**（交互停止 2.5s 后链上游标开始轻微「呼吸」）。

## 二、四个 signature

### 1. 信号链（SIGNAL PATH）
横向五格：`00 对端网元 / 01 接入层 / 02 能力矩阵 / 03 响应引擎 / 04 审计带`。
每格是实时读数（`1/3 在服 · 9 请求` / `4 挂载 · 111 接口` …）+ 一颗方形状态灯；
格子下方那条发光轨道上，**信号珠**按落点滚动：
- 普通请求 → 滚到它所属阶段，格子闪一圈光晕
- 异常（4xx/5xx）→ 珊瑚色珠子
- 命中人机交互 → 蜜桃色珠子**停在引擎格前**，闸门里有几个待放行就停几颗（呼吸闪烁）

### 2. 审计带（AUDIT TAPE / 时间机器）
底部玻璃带 = 全部审计记录的时间轴：每格一条**渐变刻度**（成功紫蓝 / 异常珊瑚 / 闸门蜜桃，且更高更亮）。
- 拖动播放头 → 进入 `review`：**审计列表、监视器窗口、检查器一起回到那一刻**（不是只动一个头）
- `◂ 步进` 回溯上一条 · `● LIVE` / `⟲ 实时` 吸附回最新 · `RATE 1×/2×/4×/8×` 改模拟器速率（分段控件）
- 键盘：`←/→` 微调、`Home` 回实时；`REC` 可冻结/恢复跟随

### 3. 人机交互闸门（GATE）
`闸门` 按钮上的计数 = 待放行数；弹层里列出每个待人工请求（方法/路径/时间/负责人/超时），
**放行** → 请求继续并在审计带留绿标；**拒绝** → 按 403 返回并留红标。
S3 升级流程里的 `human` 步骤执行时会真的停在闸门前并给一个「去闸门」的动作按钮。

### 4. 监视器（SCOPE + INSPECTOR）
左：**示波器**——近 42 秒分 32 格，紫蓝柱=成功、珊瑚=异常叠加，黄铜折线=平均时延；可切「分布」看时延直方图 + 均值虚线。
右：**检查器**——跟着当前仪器给出对象详情；引擎屏额外显示**配方预览**（`buildResponse` 的体 + 命中说明 chips），
审计记录详情里直接给出**放行 / 拒绝**。

## 四、微交互与按钮动效

**9 个 `MP.micro` 原语**（≥8 达标，且都在语义正确的位置）：

| 原语 | 落点 |
| --- | --- |
| `holdConfirm` | 按住启动 mock 服务（900ms 到满才确认） |
| `fuseButton` | 停止服务、移除软件包（完成后留引信撤销窗口） |
| `velocitySwitch` | 接口启用、账号启停、共部署开关（速度驱动的挤压开关） |
| `gauge` | 一体化任务进度、虚层 CPU 占用 |
| `statusMark` | 软件包校验状态、虚层 4 项校验、虚层 4 步流程 |
| `scrub` | 响应延迟 ms、CPU 核数 |
| `latticeLoader` | 参数校验、软件包校验、虚层校验进行中（格点波动 + 实时计时） |
| `segmented` | 审计过滤、速率 1×–8×、软件包过滤 |
| `toast` | 全部动作反馈 + 撤销入口 |

**按钮动效**：`MP.btn.install()` + 全局委托（`enhance` 后新增按钮自动生效），
`subtle` 用于抽屉/行/工具，`standard` 用于 12 个主行动条，`magnetic` 一屏只留一个焦点，
`MP.btn.loading()` **12 处**（全部 >300ms 的异步），禁用态自动降透明 + `not-allowed`。

## 五、体验与工程约束

- **重画不丢焦点**：所有重画走 `setHtml(容器, 签名, html)`——**签名不变就不碰 DOM**；
  正在输入的容器（`hasFocus`）整体跳过。所以「日志每 2.6 秒来一条」不会打断你在字段里打字，
  拖 scrub 时也不会被重画扯断。这条是硬要求，也是这版最花心思的地方。
- **零依赖 / 离线**：纯 `index.html` + `app.css` + `app.js` + `instruments.js` + `instruments2.js`，
  无 npm / 构建 / CDN / 外链字体；图标与波形全部内联 SVG / Canvas。
- **只读共享层**：`_shared/**` 一个字节都没改；本版只用 `MP.state / actions / select / motion / micro / btn / sim / sfx`。
- **响应式**：`≥1440`（示波器 340）/ `≤1439` / `≤1180`（收起节点读数）/ `≤980`（链横排换行、示波器移到台面上方、审计带吸底）/ `≤640`（页眉换行、单列表单）。
  四档 × 六屏全部 `scrollWidth <= clientWidth + 1`。
- **触控**：`@media (pointer: coarse)` 把按钮/胶囊/分段控件抬到 44px，圆形小按钮 34px。
- **诚实标注的一处**：S3「执行升级流程」的**运行游标是视图层状态**（`V6.ui.neRun`）——
  共享层的 `ne.upgrade[]` 只存步骤定义，没有「运行到第几步」这个字段，所以我没有假装它是平台数据。
  接真实后端时，把它换成服务端返回的 task 进度即可。
