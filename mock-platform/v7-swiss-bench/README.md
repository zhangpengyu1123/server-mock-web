> **V6 的卡片结构 × V2 的瑞士编辑语言。**
> 结构、交互、动效全部沿用 V6：横向**信号链** · 可回放的**审计带** · **人机交互闸门** · 示波器＋检查器 · 六台仪器抽屉。

## 保留自 V6 的东西（一个都没少）

- **信号链**：五格实时读数 + 状态灯，信号珠按落点滚动；异常珊瑚珠；命中人机交互的珠子**停在引擎格前**排队。
- **审计带时间机器**：拖播放头回到那一刻，**审计列表 / 示波器窗口 / 检查器一起倒退**；`步进`回溯、`实时`吸附、`RATE 1×–8×`。
- **闸门**：待放行请求集中放行/拒绝（放行→继续＋绿标，拒绝→403＋红标）；标本台的人工步骤会停在这里。
- **示波器＋检查器**：42→**60 秒**窗口、32 格柱状（成功蓝／异常红叠加）＋时延折线；可切时延分布。
- **六台仪器抽屉**（§5 逐条覆盖）：接入 / 引擎（**字段级五类规则**）/ 标本（升级流程含人工环节）/ 受管域（账号＋一体化任务关联站点）/ 库房（软件包四要素＋共部署）/ 虚层（CPU＋主副站点＋校验流程）。
- **动效只用技能预设**：Hover Subtle `y:-1`/150ms、Standard `y:-4 scale:1.02`/250ms、磁吸一屏 1 个、
  按下 `scale(.97)`＋涟漪＋合成音、`MP.btn.loading` 12 处、`prefers-reduced-motion` 全归零。

## 工程实现

- **逻辑层与 V6 同源**：`app.js` / `instruments.js` / `instruments2.js` 由 V6 复制，
  仅把命名空间 `V6 → V7`、主题键 `v6-theme → v7-theme`、主题文案改成「白昼 / 墨夜」。
  所以两个版本的**行为完全一致**，差异 100% 来自 `app.css`——这也让「同一套结构换一套设计语言」这件事可验证。
- **重画不丢焦点**：`setHtml(容器, 签名, html)`，签名不变不碰 DOM；输入中的容器整体跳过。
- **零依赖离线**：无 npm / 构建 / CDN / 外链字体（Inter 缺失时回退 system-ui，宋体缺失时回退 Georgia）。
- **只读共享层**：`_shared/**` 未改动。
- **响应式**：`≥1440 / ≤1439 / ≤1180 / ≤980 / ≤640` 五档；`≤980` 时链换行、监视器移到台面上方、审计带吸底。

**本轮修掉的两个真问题（V6/V7 同步修）**：
① 示波器画布被 `flex-shrink` 从 128px 压到 **33px**（容器是 flex 列）→ 加 `.scope > * { flex: 0 0 auto; }`；
② **流量模拟器从未启动**：种子数据之外不再产生请求，于是审计带／波形是静止的、`LOOP` 一直是 0 →
在 `boot()` 里 `MP.sim.start(2600 / rate)`（RATE 分段控件继续管它）。修完日志从 8 条持续增长到 14 条以上。
