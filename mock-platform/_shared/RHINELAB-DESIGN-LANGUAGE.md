# 莱茵生命 · 设计语言提取（Rhine Lab Design Language）

> 来源：本地克隆的三个同源仓库 ——
> `UI组件库/08-RhineLabUI-上游`（原作，LBEILC）、`UI组件库/06-RhineLab-Blog-Theme`（同作者博客主题 + 三维档案终端）、
> `UI组件库/07-Rhine-Music-Demo`（同语言体系的音乐台，RonaldDeng）。
> 三者共享同一套色板与排字规则；下面的数值是**从它们的源码里数出来的**，不是估的。
>
> 提取方法：对三个仓库的 `.css` / `.ts` 做十六进制色值频次统计 + 读原作的 `DESIGN.md` / `AGENTS.md` 规范条文。
> V4（档案终端）与 V5（音乐台）按本文件施工；V3 的「PRTS 维基蓝青」不是这套语言，已被本文件取代。

## 二、字体与排字

| 角色 | 字体栈 | 说明 |
| --- | --- | --- |
| 中文正文 | `MiSans` 300/400/600/700 → `"PingFang SC","Microsoft YaHei",system-ui` | 原作用 `misans-webfont@4.3.1` 分包；我们为离线不引外链，走系统回退 |
| 数字 / 编号 / 代码 | `JetBrains Maple Mono` → `"JetBrains Mono",Consolas,monospace` | 档案编号、时间、日志 |
| 拉丁展示（大写） | 原作开场用 Novecento Sans Wide（需授权，不在 Git） | 我们只用**大写 + 宽字距**的系统无衬线近似，不引字体文件 |

**排字层级（音乐台 `DESIGN.md` 明确定义，照用）**：
区块/窗口标题 **22px** · 页签与分组标题 **14px** · 设置项与主要操作 **13px** · 说明与次要操作 **12px** · 辅助小字 **11px**。
中文为主、英文为辅（大写小字副题，**一页一两处，不成排**）；正文行高 1.7。

## 三、形状与材质

- **1px 细线**是主结构手段；**几乎不用圆角**（原作按钮是细线 + 下划线，不是色块）。
- **按钮是「裸」的**（上游源码原文）：`button { border: 0; background: none; padding: 0; color: inherit; cursor: pointer }`
  —— 可点性靠排字层级、下划线与 hover 的刻度/琥珀变化表达，**不加底色、不加边框、不加圆角**。
  这也是为什么本项目的按钮动效要「只加动、不加装饰」（见 `button-fx.js`）。
- 「玻璃」= 磨砂盖板 + 内部信息层：选中时**解密扫描线自上而下扫过**，内容由磨砂变清晰。
- 强调一律靠**细线加长 / 下划线移动 / 琥珀色**，不靠填充色块。
- 交互目标最小 **44px** 高；`:focus-visible` 用 **1px 琥珀描边**；disabled **0.45 透明**；
  `::selection` 用暖杏金底 `#cbb397` + 近黑字 `#151713`。

## 四、动效家族（数值取自原作规范，直接用）

| 场景 | 时长 | 说明 |
| --- | --- | --- |
| 编号 / 标题滚动 | **460ms** | 固定两位/三位数，低强度模糊，方向跨边界时保留 |
| 页面内容切换 `ContentTransition` | **360ms** | 同一帧隐藏旧页、显示新页，共同容器从 `.35` 透明度淡入到完整 |
| 详情进出 | **180ms** | 退出更快；快速反向从当前透明度接续 |
| 弹窗 | 进 **300ms** / 出 **200ms** | 位移 12px 进 / 8px 出 |
| 页签内容 / 下划线 | **150ms / 180ms** | 下划线连续移动，不跳 |
| 收藏等状态反馈 | **220ms** | 只改按钮与计数，保留滚动位置与焦点 |
| 360° 查看器 | 进 320 / 展开 380 / 出 220ms | 复位走球面短路径 |
| hover 微交互（技能） | **150ms**（subtle）/ **250ms**（standard） | 见 `button-fx.js` |

**运动语法**：
- 一律**临界阻尼、保留速度**（改目标时从当前位置与速度接续，不重新起跳）；
- 交互停止 **2.5 秒后**进入**常态轻微波动**（缓入；原作是两个周期叠加的呼吸，单向位移约元素高度 2.8%）；
- **列与列之间异步**：相邻列有相位差，波浪依次传播而不是同时抬落；
- **不硬切**：界面/内容切换用共享元素连续过渡（`MP.motion.carry()` / `iris()`）；
- `prefers-reduced-motion` → **直接到位**，不播放（原作反复强调这一点）。

## 五、这套语言里**不该出现**的东西（V3 踩过的坑）

- ✗ 蓝青/青色系强调（`#18D1FF`、`#0098DC` 属于 PRTS 维基，不属于莱茵生命档案终端）
- ✗ 45° 危险斜纹、彩色填充的圆角按钮、糖果色状态标签
- ✗ 大面积装饰渐变、发光霓虹、Emoji 图标
- ✗ 圆角卡片 + 投影堆叠的「通用 SaaS 风」
- ✗ 一屏多个磁吸/浮动焦点（技能也明确：一屏最多 1–2 个）

## 六、V4 / V5 怎么用这套语言

| | **V4 · 档案终端** | **V5 · 音乐调测台** |
| --- | --- | --- |
| 版面 | 左侧竖排**刻度导航** + 中间档案面板 + 状态信息栏 | 顶部品牌 + 中间**卡列** + 底部 **transport 条** |
| 导航 | 六格刻度，选中加长变琥珀，配两位编号 | 密集竖刻度尺（`music-navigation-ruler` 的做法） |
| 卡片 | 磨砂玻璃盖板 + **解密扫描线**揭示内部 | 专辑卡式端点卡，**异步波浪**选中 |
| 主题 | 晨雾（亮）为主，深夜（暗）可选 | **晨雾 / 月影双主题**，连续过渡 |
| 签名动效 | 460ms 编号滚动 + 180ms 详情 + 解密扫描 | 360ms `ContentTransition` + 常态波动 + 频谱 |
| 按钮 | 细线 + 下划线，`ACCESS FILE` 式主行动 | 大圆形 transport 主控 + 细线工具按钮 |
| 共同 | `MP.btn`（技能动效预设）+ `MP.micro`（≥8）+ `_shared/domain.js`（同一批数据） | 同左 |
